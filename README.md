# Task 4: Classification with Logistic Regression

## Objective
The objective of this task is to build a binary classification model using Logistic Regression and understand how it is used to classify data into two categories.

## Dataset
**Breast Cancer Wisconsin (Diagnostic) Dataset**

The dataset contains information about breast cancer tumors and is used to classify them as benign or malignant.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Work Performed
1. Imported the required libraries and loaded the dataset.
2. Explored the dataset and checked its structure and class distribution.
3. Divided the data into training and testing sets.
4. Standardized the features using StandardScaler.
5. Built and trained a Logistic Regression model.
6. Made predictions and adjusted the classification threshold.
7. Evaluated the model using a confusion matrix, precision, recall, and ROC-AUC score.
8. Created visualizations of the confusion matrix, ROC curve, and sigmoid function.

## Model Evaluation Results

| Metric | Result |
|---|---:|
| Precision | 1.0000 |
| Recall | 0.9048 |
| ROC-AUC Score | 0.9960 |
| Selected Threshold | 0.65 |
